# 创建 Multica 任务

面板中文名：创建任务。本目录才是执行步骤；看板那一行只含 `repo` + `dir`。

Issue 统一叫**任务**。在网页版看板「手动创建」。规范源：`D:\multicaws` 下最新的 `HD-multica看板约束-*.md`。禁止修改 `D:\share`。

## 何时用 / 何时不用

- **用：** 用户说「创建任务」「建任务」；普通 / 单条执行 / `[修复]` / 单条 `[自测]`。
- **不用：** 闲聊、讲用法、只改规范文档。
- **不用本 skill（阶段触发）：** 创建项目、立刻评审/开始评审、开始计划、按计划建任务、提测、软测开始、挂网、跟进、改计划。

修代码细节、单点 bug：有所属项目（含已挂网）→ 该项目下一条执行任务，标题可加 `[修复]`；无处可挂 → 只建任务、不进项目。禁止为此新建项目、禁止设「临时任务」项目。

## 环境

- 看板：http://172.16.0.67:3000 ，工作区 **XTOOL-HD**（URL 里是 `/test/`）
- 只用网页 **「手动创建」**。禁止 daemon、`multica login`、轮询、派智能体、GitHub/本地目录资源、自定义工作流（保持 Default）
- 禁止点「切换到智能体」或「和 Mika 开始」；负责人从成员里选
- 禁止把本机路径、密钥、C 盘列表写入描述/评论/聊天
- 问题框用 `ask_user_question`：每轮最多 4 题；每题 2–4 个选项；自定义走卡片自带「其他」，禁止再加「其他」选项
- 题干用字段原名。禁止自造题目、禁止用「还要补充的背景」顶替交付物或验收人
- 收齐后直接创建，禁止再问「要不要创建」
- 全部平级，禁止把执行拖成评审/计划的子任务

## 写死默认（禁止再问）

- 状态：**待办**
- 只 @ **负责人**（禁止 @all，除非用户选了）
- 截止日期 **禁止**抄最近一条任务的截止日期

## 第 1 轮问题框

1. **标题** — 用户话里已有则作推荐项。自测则标题加 `[自测]`；修复可加 `[修复]`。前缀白名单：`[评审]` `[计划]` `[自测]` `[提测]` `[软测]` `[挂网]` `[修复]`；普通执行无前缀。本 skill 不要主动建 `[评审]` `[计划]` `[提测]` `[软测]` `[挂网]`
2. **负责人** — 黄灿（Recommended）、何荣怀、罗千翔、邓金
3. **截止日期** — 2–4 个日期选项；用户走「其他」填 YYYY-MM-DD。禁止抄最近一条 due
4. **优先级** — 低 / 中 / 高 / 紧急

## 第 2 轮问题框（交付物、验收人必问）

1. **挂哪个项目** — 当前打开的项目（写出项目名）/ 最近项目（写出项目名）/ 不进项目。需要别的项目走「其他」
2. **交付物** — 产出是什么。选项示例：技术方案文档 / 代码或功能上线 / 设计稿或原型（第 4 项不要写「其他」）。工作量需要时写在「其他」里，禁止挤掉验收人
3. **验收人** — 黄灿（Recommended）、何荣怀、罗千翔、邓金

## 网页创建

走「手动创建」：

- 标题、负责人、截止日期、优先级、项目按答案
- 状态 = 待办；只 @ 负责人
- 描述在**新建对话框**可按下面结构写；提交后检查页面标题是标题样式，**不得**显示「## 交付物与验收」，不得残留 `#` `*`

```
## 交付物与验收
{产出}，由 {验收人} 验收
```

再补：任务说明、起止、负责人。禁止写本机路径、密钥、C 盘列表。

若创建后打开已有任务改描述：**禁止**再贴 `## `。只写标题文字，用编辑器设为标题（Windows：Ctrl+Alt+2），写回后检查没有多余 `#`。

建好后回报 **HD-n 和链接**。禁止代关本任务（执行/自测由项目负责人关）。
